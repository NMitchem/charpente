# M1 sub-project 3 — realtime SSE with exact resume: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SSE event tails with exact resume-from-cursor: `tx.emit`/`emit_keyed` materialize into a retained `charpente.events` table; app-defined `#[route(SSE …)]` handlers return typed `Subscription`s; the kernel delivers via one bounded-read path; a reconnecting client provably misses no events (PLAN M1 exit criterion).

**Architecture:** Spec docs/superpowers/specs/2026-07-14-realtime-design.md governs. Apply materializes emits into `charpente.events` (`next_event_id` meta counter, the `next_job_id` pattern); the cursor is the event id, wire-encoded `<id>.<seq>` so failover divergence is a named error, never misattribution. The kernel gains a Tail ready-source: delivery is always a bounded table read (no live/catch-up modes); the sink is driver-supplied (bounded channel in prod, `SimSink` in sim); `Full`/`Closed` drops the tail and cursor resume is the recovery.

**Tech Stack:** existing workspace only — no new dependencies. serde/serde_json re-exported through `charpente` for the `#[event]` wire derive.

## Global Constraints

- Commit directly to `main`, no Co-Authored-By trailers. One commit per task unless a task says otherwise.
- **Frozen replay contracts (violating any is a Critical defect):** `FaultConfig::swarm`'s sequential draw order (`crates/charpente-sim/src/lib.rs`) gains no draws; `run_universe` is untouched; the new `subscriber_stall` field defaults to `0.0` and takes **zero RNG draws when 0.0**; it samples ONLY via `sample_extended_fields`'s field-keyed sub-streams (`keyed_stream(seed, "subscriber_stall")`). The global sim world and every pre-existing pinned seed replay byte-identically — the pin test that froze prior sampling gets the new field appended with `0.0`, nothing else moves.
- New fault axes strengthen properties, never weaken assertions. The received≡emitted oracle is a consistency oracle: NEVER excused by `checks::durable_corruption_fired`.
- Every new fence ships in the same task as its meta-test (a naive victim the harness must catch, by name) — hard rule 3.
- Error messages are product surface (hard rule 5), all pinned by tests against text: cursor-below-floor 409 (floor, client cursor, re-sync fix), cursor-diverged 409 (both sides: cursor id.seq vs node's row seq or next id, re-sync fix), mid-stream `event: charpente.gap` terminal frame (same three facts).
- `cargo fmt --all --check` and `cargo clippy --workspace --all-targets -- -D warnings` clean before every commit.
- Constants, fixed here so tasks agree (all deterministic, no entropy draws): `TAIL_BATCH_EVENTS: usize = 64` (kernel); `EVENT_SINK_BUFFER: usize = 256` (serve edge); `DbConfig::event_retention: u64 = 65_536`; SSE heartbeat 15s (edge-only, non-semantic).

```rust
// http/mod.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Cursor { pub id: u64, pub seq: u64 }
impl Cursor {
    /// Wire form "<id>.<seq>". None for an unparseable string — the caller
    /// maps that to the 400 below, never a silent from-now.
    pub fn parse(s: &str) -> Option<Cursor>;
    pub fn wire(&self) -> String; // format!("{}.{}", id, seq)
}

pub struct SubEntry {
    pub name: &'static str,
    pub encode_json: fn(&[u8]) -> std::io::Result<String>,
}
pub struct Subscription {
    pub entries: Vec<SubEntry>,
    pub key: Option<String>,
    pub cursor: Option<Cursor>,
}
impl Subscription {
    pub fn of<Ev: Event + serde::Serialize>() -> Subscription;
    pub fn and<Ev: Event + serde::Serialize>(self) -> Subscription;
    pub fn key(self, key: impl Into<String>) -> Subscription;
    pub fn cursor(self, cursor: Option<Cursor>) -> Subscription;
}

// kernel/mod.rs — replaces `pub type Reply = Box<dyn FnOnce(Response) + Send>;`
pub trait Respond: Send {
    /// One-shot: this response ends the exchange.
    fn send(self: Box<Self>, response: Response);
    /// The SSE upgrade: deliver the stream-opening response, return the sink
    /// the kernel pushes frames into for the rest of the connection.
    fn stream(self: Box<Self>, response: Response) -> Box<dyn EventSink>;
}
pub type Reply = Box<dyn Respond>;

// kernel/tail.rs (created in T5; the trait lands HERE in T4 so Respond compiles)
pub enum SinkStatus { Ok, Full, Closed }
#[derive(Clone, Debug)]
pub struct EventFrame { pub id: u64, pub seq: u64, pub name: &'static str, pub json: String }
// Clone is load-bearing: the prod sink's try_send takes an owned frame.
pub trait EventSink: Send { fn send(&mut self, frame: &EventFrame) -> SinkStatus; }
```

```rust
/// One bounded unit: read up to TAIL_BATCH_EVENTS rows from next_id, filter,
/// push. Returns whether the tail survives. The floor check runs FIRST: a
/// tail that fell behind retention gets the terminal gap frame and dies —
/// deterministic, part of the unit.
pub fn deliver_unit(tail: &mut Tail, db: &Db) -> io::Result<bool> {
    let floor = db.event_floor()?;
    if tail.next_id < floor {
        let gap = EventFrame {
            id: tail.next_id, seq: 0, name: "charpente.gap",
            json: format!(
                "{{\"floor\":{floor},\"tail\":{},\"fix\":\"re-sync current state through reads, then reconnect without a cursor\"}}",
                tail.next_id
            ),
        };
        let _ = tail.sink.send(&gap);
        return Ok(false);
    }
    let rows: Vec<EventRow> = db.snapshot()?.scan_from(tail.next_id, TAIL_BATCH_EVENTS)?;
    for row in rows {
        tail.next_id = row.id.raw() + 1;
        let matched = tail.sub.entries.iter().find(|e| e.name == row.name);
        let (Some(entry), true) = (matched, tail.sub.key.is_none() || tail.sub.key.as_deref() == row.key.as_deref()) else { continue };
        let frame = EventFrame { id: row.id.raw(), seq: row.seq, name: entry.name, json: (entry.encode_json)(&row.payload)? };
        match tail.sink.send(&frame) {
            SinkStatus::Ok => {}
            SinkStatus::Full | SinkStatus::Closed => return Ok(false),
        }
    }
    Ok(true)
}
```

  - Dead tails are removed after the arm (swap_remove by index, order-stable alternative fine — pick one and keep registry iteration deterministic).
