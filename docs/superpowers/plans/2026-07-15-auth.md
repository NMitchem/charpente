# M1 sub-project 4 — auth: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** hashed session tokens with expiry, API keys, static-JWKS OIDC verification, and a replication-port peer secret — all built-in tables and route guards inside the commit point, all sim-tested, with the raw-credential-never-hits-disk guarantee proven mechanically.

**Architecture:** Spec docs/superpowers/specs/2026-07-15-auth-design.md governs. Credentials hash to SHA-256-at-rest; a pre-transaction resolution ladder (JWT→OIDC verify, else hash→ApiKey index→Session index, else cookie) yields one `Principal`; `#[route(…, auth)]` gates on it. OIDC is pure RS256 verification against configured JWKS. The replication `Hello`/Ctrl messages carry an optional secret, refused by name on mismatch. Everything is pure computation plus the kernel `Clock` — deterministic in sim.

**Tech Stack:** RustCrypto — `sha2` (hashing), `rsa` + `sha2` (RS256 verify), `base64ct` (base64url). Pure Rust, no IO/threads/time inside the deterministic boundary.

## Global Constraints

- Commit directly to `main`, no Co-Authored-By trailers. One commit per task unless a task says otherwise.
- **Frozen replay contracts (violating any is Critical):** the auth work adds **ZERO new entropy draws** — both credential kinds are fed by the single existing pre-transaction `fresh_token` draw (`http/app.rs:298-300`); one credential mint per request (session OR api key), enforced by the existing `created` once-assert. The Session-table reshape and the repl `Hello`/Ctrl wire change are pre-release breaking changes with no migration. `FaultConfig::swarm`'s draw order is untouched; every pinned seed replays byte-identically (the frozen suites green is the proof).
- New dependencies (`sha2`, `rsa`, `base64ct`) land in `crates/charpente/Cargo.toml` with a one-line justification in the commit body AND a `clippy.toml` review confirming they introduce no ambient-IO/threading/time deny-list needs (they don't — verify with `cargo tree` that none pulls tokio/rand-with-os/std-time). They live in `charpente`, never `charpente-core`.
- Error messages are product surface (hard rule 5), all pinned by tests against text: the exact final strings are fixed as each task implements them and MUST be copied verbatim into that task's test assertions (never approximated). The spec §6 list is the required set.
- No hand-rolled crypto anywhere. Hashing/verification go through the RustCrypto crates only.
- Repl peer-secret compare is constant-time: compare SHA-256 digests, never raw `==` on the secrets.
- `cargo fmt --all --check` and `cargo clippy --workspace --all-targets -- -D warnings` clean before every commit.
- Sim-first: each task ends with its affected suites green over fresh seeds; Task 9 runs the full evidence bar. Any sim-found bug lands with its seed pinned.
- Constants (deterministic, no entropy): `SESSION_TTL` default 30 days in nanos (`30 * 24 * 60 * 60 * 1_000_000_000`), an `AppConfig` field; `JWT_CLOCK_SKEW_NANOS: u64 = 60_000_000_000`; the sweep cron cadence is daily (`Duration::from_secs(86_400)`). Token formats: session = 64 hex chars (today's shape); API key = `"ck_"` + 64 hex.

```rust
//! Credential hashing. Raw tokens/keys/secrets never reach the durable store
//! (DESIGN §8) — only these SHA-256 hex digests do.
use sha2::{Digest, Sha256};

/// Lowercase-hex SHA-256 of a raw credential.
pub fn hash_token(raw: &str) -> String {
    let digest = Sha256::digest(raw.as_bytes());
    let mut out = String::with_capacity(64);
    for byte in digest {
        out.push_str(&format!("{byte:02x}"));
    }
    out
}

/// Constant-time equality of two hex strings. Unequal lengths return false
/// without leaking via early exit past the length check (the length of a
/// hash is not secret). Used for the repl peer-secret compare.
pub fn ct_eq_hex(a: &str, b: &str) -> bool {
    let (a, b) = (a.as_bytes(), b.as_bytes());
    if a.len() != b.len() {
        return false;
    }
    let mut diff = 0u8;
    for i in 0..a.len() {
        diff |= a[i] ^ b[i];
    }
    diff == 0
}
```
