# 0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 0.5.0. An app stops keeping its own copy of four things the platform holds:
- a transaction reads its time (`tx.now()`);
- a job can be due at a time;
- every job says what its Dead means, and a hook runs in the Dead mark's own record;
- a redrive from that hook resends the same request under the same key;
- and an outbound job reaches Dead in the sim, under a drawn provider outage.

**Architecture:**
- **Time.** It rides the `Group`, not the log. Each kernel arm sets the step's held
  `Now.wall` on the group it opens. `Group::stage` copies it into each `Tx`. A group nobody
  gave a time refuses `tx.now()` by name.
- **Timed enqueues.** They are one new record tag, `0x0e`, with a flags byte. The due time
  travels record → `materialize_job` → `Enqueued` → `note_enqueued`, and never through a
  store read (amendment A8).
- **The Dead stance.** It is a required `#[job]` word, `on_dead` or `retain_dead`, carried
  on `JobDef` and never in `FINGERPRINT`.
- **The hook.** It runs inside the failure stage, through the same `JobScope` and capability
  minting `run_due_into` does. If it fails, a fallback stage commits the mark alone, under
  a pinned `last_error` prefix that only the platform can write at the start.
- **Re-issue.** It consumes `Dead<J>` and stages the dead job's own payload bytes as a timed
  enqueue whose key is supplied. The minting loop skips that key.
- **The outage.** It is an app-only, keyed sim axis that outlives `quiesce_outbound_faults`.
  Drive's tail extends itself until outbound work is settled, Dead or not yet due.

## Review Focus

1. **A hook that enqueues a fresh job (not a re-issue) on every Dead, during a 4 h outage.**
   The chain must end when the outage ends, inside Drive's tail cap. It must not hit the cap
   or loop without end. Test in Task 11.
2. **`tx.now()` on a follower's read route.** It must return the follower's own held
   reading. It must neither panic with the no-time refusal nor read the epoch. Test in Task 1.
3. **A scoped job's hook that re-issues.** The re-issued job must carry its tenant and run
   in the same tenant. Test in Task 9.
4. **An app error text that begins with the hook-failure prefix.** It must not read as a
   hook failure to `dead_hooks_succeeded`. Test in Task 7.
5. **`enqueue_after(Duration::MAX, job)`, or a due time centuries out.** It must not panic
   on overflow. The job saturates to the far future and stays Pending. Test in Task 3.
