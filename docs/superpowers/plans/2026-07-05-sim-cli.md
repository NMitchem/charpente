# M0 Step 7 — `charpente test --sim` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The CLI that makes the simulator the app developer's inner loop — app-authored sim tests swarmed across parallel seeded universes, with failure output that is a one-command reproduction (spec: docs/superpowers/specs/2026-07-05-sim-cli-design.md).

**Architecture:** A `harness` module in charpente-sim reuses the frozen single-universe executor behind a new batch orchestrator (master seed → splitmix per-universe seeds, thread pool, per-universe catch_unwind); a `sim_tests!` macro_rules generates the app's `tests/sim.rs` main; the `charpente` binary builds the app's `sim` target via cargo and execs it directly so exit codes stay exact. Also closes step 6's request-arm question: stop-only-when-poisoned.

**Tech Stack:** Rust only. **Zero new dependencies** — JSON output is hand-rolled (~40 lines), arg parsing is hand-rolled, the CLI shells out to cargo via `std::process`.

## Global Constraints

- CLAUDE.md hard rules apply to every task; read it before starting.
- **Zero new dependencies in any crate.** No serde, no clap, no rayon. If you think you need one, the plan is wrong — stop and say so.
- **The frozen replay contract is untouchable:** `run_universes!`, `run_universes_swarm!`, `run_universes_from!`, their `*_in` functions' observable behavior, and the seed→universe derivation (`splitmix64(seed)` → `FaultConfig::swarm`) must be byte-identical after your change. Every pinned seed in the repo must still pass.
- Error messages are product surface (DESIGN §7): every new failure message names the contract, the site, and the fix, and gets a test asserting its text.
- `std::thread::spawn` and `std::process` are outside-the-boundary tools: thread use is allowed ONLY in `charpente-sim/src/harness.rs` with a site-local `#[allow(clippy::disallowed_methods)]` + rationale comment (the pattern `ambient_base_seed` already uses); `std::process` only in charpente-cli.
- Commits go directly to `main`, no Co-Authored-By trailers. Core-adjacent commits state their sim evidence ("N fresh universes green").

```rust
//! Reusable oracles for sim workloads (step-7 spec §Platform-checker
//! library). v0 ships exactly three; more earn their way in when the demo
//! app demands them.

/// The three recognized fault-fallout families (extracted from the internal
/// suite, which had hand-rolled this four times):
///  1. the sim's own injected-fault wordings,
///  2. our WAL/engine poison wording,
///  3. redb's latch ("close and re-open the database") — its internal
///     already-saw-an-IO-error signal.
/// Anything else is NOT fallout and must fail the universe for adjudication.
/// Recognizing these cannot mask a real bug so long as the workload's
/// end-state oracle (e.g. exactly-once on reopen) still runs either way.
pub fn is_fault_fallout(text: &str) -> bool {
    text.contains("simulated")
        || text.contains("injected")
        || text.contains("poisoned")
        || text.contains("close and re-open the database")
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn recognizes_all_three_families_and_nothing_else() {
        for fallout in [
            "simulated disk write error (injected fault)",
            "simulated fsync failure — durability of writes since the last successful sync is unknown",
            "WAL poisoned by an earlier IO failure",
            "engine poisoned: a durable record failed to apply",
            "Storage error: close and re-open the database",
        ] {
            assert!(is_fault_fallout(fallout), "must classify: {fallout}");
        }
        for real_bug in [
            "row decode: needed 8 bytes for u64, 3 left — schema drift or corruption",
            "assertion failed: durable.is_some_and(|d| d >= applied)",
            "exactly-once violated: hits 3, done 2 for key 7",
        ] {
            assert!(!is_fault_fallout(real_bug), "must NOT classify: {real_bug}");
        }
    }
}
```

```rust
/// One universe, shared by the frozen swarm macro and the CLI harness
/// (harness.rs). The seed→behavior mapping here is the frozen replay
/// contract: config derives from `splitmix64(seed)`, the workload runs
/// under catch_unwind, Ok returns coverage. Do not reorder anything.
pub(crate) fn run_universe(
    seed: u64,
    f: &dyn Fn(&mut Sim) -> Result<(), String>,
) -> Result<BTreeMap<&'static str, u64>, (FaultConfig, String)> {
    let mut s = seed;
    let cfg_seed = splitmix64(&mut s);
    let cfg = FaultConfig::swarm(&mut Rng::new(cfg_seed));
    let mut sim = Sim::with_faults(seed, cfg.clone());
    match std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| f(&mut sim))) {
        Ok(Ok(())) => Ok(sim.coverage()),
        Ok(Err(msg)) => Err((cfg, msg)),
        Err(payload) => Err((cfg, panic_message(&*payload))),
    }
}
```

then rewrite `run_one_swarm` as:

```rust
fn run_one_swarm(

    test_file: &str,
    seed: u64,
    f: &impl Fn(&mut Sim) -> Result<(), String>,

        Ok(coverage) => coverage,
        Err((cfg, msg)) => panic!("{}", swarm_failure_report(package, test_file, seed, &cfg, &msg)),

}
```

```rust
    let mut db = match Db::open(Box::new(sim.disk()), DbConfig::default(), schema()) {
        Ok(db) => db,
        Err(e) => return fallout_ok(e.to_string()),
    };
    let acked = db
        .transact(|tx| {
            tx.put(&FixtureCounter { id: Id::from_raw(7), hits: 1 });
            Ok::<_, std::io::Error>(())
        })
        .is_ok();
    sim.restart();
    drop(db);
    let db = match Db::open(Box::new(sim.disk()), DbConfig::default(), schema()) {
        Ok(db) => db,
        Err(e) => return fallout_ok(e.to_string()),
    };
    if acked {
        let snap = db.snapshot().map_err(|e| e.to_string())?;
        let row = snap.get::<FixtureCounter>(Id::from_raw(7)).map_err(|e| e.to_string())?;
        if row.is_none() {
            return Err("acked FixtureCounter row lost across a crash".into());
        }
    }
    Ok(())
}

fn sometimes_fails(sim: &mut Sim) -> Result<(), String> {
    if std::env::var_os("CHARPENTE_FIXTURE_FAIL").is_none() {
        return Ok(());
    }
    let mut byte = [0u8; 1];
    sim.entropy().fill(&mut byte);
    if byte[0] % 5 == 0 {
        Err(format!("fixture failure: entropy byte {} ≡ 0 (mod 5)", byte[0]))
    } else {
        Ok(())
    }
}
```
